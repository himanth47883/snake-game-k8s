# Snake Game - Kubernetes Deployment

A classic Snake Game with modern UI, ready for Kubernetes deployment.

## Features
- 🎮 Classic snake gameplay
- 🎨 Modern gradient UI
- 📊 Score tracking & level system
- 🏆 High score persistence (local storage)
- 🐳 Docker & Kubernetes ready
- ⚡ Auto-scaling support

## Quick Start

### Local Development
```bash
# Install dependencies
pip install -r requirements.txt

# Run locally
python app.py

# Open browser and go to
